# 风投人生

一个 VC 职业生涯模拟游戏。你刚成立了自己的基金，接下来十五年要从源源不断的 BP 里挑公司、和四家对手机构抢项目、陪被投公司熬过低谷，再用业绩说服 LP 给你更大的下一期基金。

**在线玩：** https://hukairui228.github.io/vc-life/

整个游戏就是一个 `index.html`，不需要安装任何东西。进度保存在你自己的浏览器里。

## 玩法

- **时间按周走。** 可以暂停（空格）或调成三档速度。每周只有几个小时块，约见、尽调、开董事会、见 LP 都要花时间。
- **好项目要抢。** 每个项目都有关账日期，对手机构也会递 TS，创始人选条款更好、名气更大的那家。
- **投完才是开始。** 跟投、过桥贷款、联创内斗、收购要约，被投公司的事会一直找上门，邮件都有回复期限。
- **业绩决定下一期。** 一期投出一半就能募二期。TVPI、DPI 和声誉好看，LP 才会给你更大的基金。
- **赛道专长和团队。** 投哪个赛道多，那个赛道看得越准；管理费可以拿来招人，给你每周多一些时间。

## 让创始人用 AI 说话（可选）

默认用离线剧本回答问题。想让创始人根据公司真实底细即兴路演、回答任何问题：

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/) 申请一个 API Key。
2. 游戏里点左下角「AI 路演引擎」，选 DeepSeek，填入 Key，点「测试连接」。

Key 只保存在你自己这台设备的浏览器里，只会发给 `api.deepseek.com`，按 DeepSeek 的价格计费。每个玩家用自己的 Key。

## 本地运行

下载 `index.html`，用 Chrome、Safari 或 Edge 直接打开即可，DeepSeek 在本地打开时也能用。
